# 単語・イディオム一覧

> `english-translate` スキルが追記する学習ログ（保存兼一覧）。
> 中学生以上の語彙を蓄積する。`種別` は `word`（単語）／ `idiom`（イディオム）。

| 種別 | 単語・イディオム | 意味 | 用例 |
|------|------------------|------|------|
| word | exclude | 除外する | The rule excludes infra work by default. |
| word | proceed | 進める、続行する | How should I proceed? |
| word | override | 無効化する、優先させる | You can override the default setting. |
| word | explicitly | 明示的に | You explicitly authorize this work. |
| word | authorize | 承認する、権限を与える | I need you to authorize the change. |
| word | risky | リスクの高い | Riskier changes still get review. |
| word | chore | 雑用、雑務 | Do only the safe chores. |
| word | literally | 文字通りに | Follow the skill literally. |
| word | manually | 手動で | You'll hand these off manually. |
| word | destroy | 破壊する、削除する | There is no terraform destroy. |
| idiom | blast radius | 影響範囲（被害の及ぶ範囲） | We excluded it due to its large blast radius. |
| idiom | hand off | 引き継ぐ、任せる | You'll hand these off manually. |
| word | organize | 整理する、まとめる | I spent the morning organizing the issues. |
| word | triage | 優先順位をつけて選別する | We need to triage the open issues first. |
| word | translate | 翻訳する | Please translate this request into English. |
| word | request | 依頼、要望 | Translate this request itself. |
| word | itself | それ自体 | Translate the request itself, not the example. |
| word | review | レビューする、精査する | The human review is complete. |
| word | complete | 完了した、完成した | The review is complete. |
| word | merge | （変更を）統合する、マージする | Please review and merge it. |
| idiom | close out | 完了させる、締める | Please close out the task. |
| word | approve | 承認する | I've approved the draft. |
| word | draft | 下書き、草案 | I approved the draft. |
| word | ready | 準備ができた | I marked it as ready. |
| word | resume | 再開する | Please resume. |
| word | standardize | 統一する、標準化する | We are standardizing the Sample cases. |
| word | case | 案件、事例 | Each Sample case needs review. |
| word | unify | 統一する、一体化する | Let's unify these items. |
| word | instinct | 本能、直感、勘 | Her instinct told her something was wrong. |
| word | option | 選択肢、案 | Please proceed with Option A. |
| word | investigation | 調査 | Thank you for the investigation. |
| idiom | look into | 調べる、調査する | Thank you for looking into this. |
