# PBI Point 傾向蓄積ログ

> 将来 PBI 作成時に Point を提案するための学習データ。
> `scrum-notion-pbi` スキルが PBI 作成時にヒアリングした「ステップ数」「難易度」「Point」を蓄積する。
> 難易度の評価はユーザー（Ueki Masaya）の感覚によるところが大きいため、現時点は自動算出せず、すべてユーザーへのヒアリングで取得する。
> 対象は通常PBIのみ。「イベント」種別PBI（Point=null。[scrum-notion-pbi](../../../.claude/skills/scrum-notion-pbi/SKILL.md) 参照）は価値提供に直結しないため蓄積対象外。
