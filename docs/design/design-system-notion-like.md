# Notion ライク デザインシステム（Claude Design 用）

> **これは何か**: Claude Design（claude.ai/design）に読み込ませる**デザインシステム定義ファイル**。
> スライド・ドキュメント・UI モックのいずれを作らせても、同じ見た目に着地させるための唯一の基準。
> **使い方・運用**: [docs/design/README.md](./README.md) ／ **採用理由**: [ADR-0016](../adr/0016-claude-design-design-system-file.md)

コミュニティで定着している `DESIGN.md` 形式（9 セクション構成）に従う。
Claude Design はこのファイル 1 枚を読めば、未定義のケースに出会っても「なぜそうするのか」から判断できる。

---

## 1. Visual Theme & Atmosphere（世界観）

**コンセプト**: Notion ライク。**余白と罫線だけで構造を示す**、静かな文書型インターフェース。

| 軸 | 立ち位置 |
|---|---|
| 密度 | 低〜中。詰め込むより、分割する |
| 彩度 | 極小。色は「意味」が必要なときだけ使う |
| 装飾 | なし。影・グラデーション・立体・イラストを使わない |
| 温度 | ややウォームなニュートラル（純黒 `#000` / 純グレー `#808080` は使わない） |
| 声のトーン | 事実ベース・断定的・短い。煽らない |

**なぜ**: 情報そのものを主役にするため。装飾で差をつけるのではなく、**余白のリズムと階層の一貫性**で読みやすさを作る。判断に迷ったら「引く」方を選ぶ。

**背景は必ずウォームホワイト `#FFFFFF`、文字はウォームブラック `#37352F`。** この 2 色が世界観の土台で、ここを崩すと Notion らしさは失われる。

## 2. Color Palette & Roles（配色と役割）

```css
:root {
  /* Text */
  --text:            #37352F;  /* 本文・見出し（ほぼ黒／ウォーム） */
  --text-muted:      #787774;  /* 補足・キャプション・出典・プレースホルダ */
  --text-disabled:   #9B9A97;  /* 非活性 */
  --text-on-accent:  #FFFFFF;

  /* Surface */
  --bg:              #FFFFFF;  /* 基本背景 */
  --bg-subtle:       #F7F6F3;  /* カード・ゾーニング・表ヘッダー */
  --bg-hover:        #F1F1EF;  /* ホバー・選択行 */

  /* Line */
  --border:          #E9E9E7;  /* 罫線・区切り（常に 1px） */
  --border-strong:   #D3D1CB;  /* 入力欄・フォーカス外枠 */

  /* Accent（唯一の有彩色） */
  --accent:          #2383E2;
  --accent-hover:    #0B6BCB;
  --accent-soft:     #DDEBF7;  /* 面塗り・強調行 */

  /* Semantic（状態表示のみ。装飾に使わない） */
  --success:         #448361;
  --warning:         #CB912F;
  --danger:          #D44C47;
  --success-soft:    #EDF3EC;
  --warning-soft:    #FBF3DB;
  --danger-soft:     #FDEBEC;
}
```

### 役割ルール

| ルール | 内容 |
|---|---|
| **有彩色は accent 1 色** | 画面／1 ページに accent を使う箇所は **1〜2 か所まで**。それ以上は「どれも目立たない」と同義 |
| **semantic は状態専用** | success / warning / danger は**状態を表すときだけ**。強調・装飾・グラフの系列色に流用しない |
| **文字色は 3 種** | `--text` / `--text-muted` / `--accent`。それ以外の色で文字を塗らない |
| **色に意味を委ねない** | 「赤＝悪 / 緑＝良」だけで伝えない。必ず語・記号・順序を併記する（色覚多様性・白黒印刷対策） |

### 図表 3 色ルール（最重要）

**グラフ・表・図で使える色は次の 3 色だけ。** この 3 色をまとめて **`chart_palette`** と呼ぶ。

値は 2 章のトークンを参照する（hex を書き写さない。§2 を直せば図表にも伝わる）。

```css
:root {
  --chart-1: var(--accent);
  --chart-2: var(--text-muted);
  --chart-3: var(--border);
}
```

| # | トークン | 実体 | 役割 |
|---|---|---|---|
| 1 | `--chart-1` | `--accent` | 注目させたい系列・推奨案・現在地 |
| 2 | `--chart-2` | `--text-muted` | 比較対象・その他 |
| 3 | `--chart-3` | `--border` | 母数・背景・非注目 |

**例外**: 構成説明図・状態遷移図など、**色が意味の識別そのものを担う**場合に限り 4 色目以降を許可する。その場合も彩度を抑えたトーンで統一し、図の中に凡例を置く。**「見栄えのため」は例外理由にならない。**

## 3. Typography Rules（タイポグラフィ）

```css
--font-sans: "Inter", "Noto Sans JP", ui-sans-serif, -apple-system, "Segoe UI", Helvetica, Arial, sans-serif;
--font-mono: "JetBrains Mono", ui-monospace, SFMono-Regular, Menlo, monospace;
```

Google Fonts 代替: **Inter**（欧文）＋ **Noto Sans JP**（和文）。等幅は **JetBrains Mono**。
和欧混植では和文フォントを後ろに置き、欧文を Inter に拾わせる。

### スケール（Web / ドキュメント）

| 用途 | size | weight | line-height | color |
|---|---|---|---|---|
| H1 | 40px | 700 | 1.2 | `--text` |
| H2 | 30px | 600 | 1.3 | `--text` |
| H3 | 24px | 600 | 1.3 | `--text` |
| Body | 16px | 400 | 1.5 | `--text` |
| Small / Label | 14px | 500 | 1.4 | `--text` |
| Caption | 12px | 400 | 1.4 | `--text-muted` |

和文は欧文より字面が大きいため、**本文の line-height は 1.5 を下限**とし、長文は 1.7 まで上げてよい。

### ルール

- **太字は 1 画面 3 か所まで。** 下線・斜体・影文字・全角スペースでの字下げは使わない
- 見出しは階層を飛ばさない（H1 → H3 のスキップ禁止）
- 本文 1 文は **40 字以内**。超えたら文を割る
- 数字・英字は半角。単位は数値と半角スペースで区切る（`1,240 件`）
- 本文サイズを下げて情報を詰めない。入らないならページ／セクションを分ける

## 4. Component Stylings（コンポーネント）

すべて **枠線 1px＋弱い面色** で構成し、影は原則使わない（→ 6 章）。

### Button

| variant | 背景 | 文字 | 枠線 |
|---|---|---|---|
| primary | `--accent` | `--text-on-accent` | なし |
| secondary | `--bg` | `--text` | 1px `--border-strong` |
| ghost | 透明 | `--text` | なし |
| danger | `--danger` | `#FFFFFF` | なし |

共通: `height 32px` / `padding 0 12px` / `radius 4px` / `font-size 14px` / `font-weight 500`
状態: `hover` = 背景を 1 段濃く（ghost/secondary は `--bg-hover`） / `active` = さらに 1 段 / `focus-visible` = `outline 2px --accent, offset 2px` / `disabled` = `opacity .5, cursor not-allowed`

### Input / Select / Textarea

`height 32px` / `padding 0 10px` / `radius 4px` / `1px solid --border-strong` / `bg --bg`
`focus` = 枠線 `--accent` ＋ `box-shadow 0 0 0 3px --accent-soft`。プレースホルダは `--text-muted`。
エラー時は枠線 `--danger` ＋ 下にメッセージ（`12px --danger`）。**枠線の色だけでエラーを示さない。**

### Card

`bg --bg-subtle` / `radius 8px` / `padding 24px` / **枠線なし・影なし**
背景の上に置く場合のみ `1px solid --border` を許可（面色と枠線は併用しない）。

### Table

- **横罫線のみ。縦罫線は引かない**（`border-bottom 1px solid --border`）
- ヘッダー行: `bg --bg-subtle` ＋ Label スタイル（14px/500）
- セル: `padding 12px 16px` / 数値は右揃え・等幅 / 文字は左揃え
- 行 hover: `--bg-hover`。強調行は `--accent-soft`（1 行まで）
- **表の下には必ず結論を 1 行置く**（表は主張ではなく根拠）

### Callout

左に `4px` の `--accent` バー ＋ 背景 `--bg-subtle` / `padding 16px 20px` / `radius 0 4px 4px 0`。
semantic を使う場合はバーと背景をペアで替える（`--danger` ＋ `--danger-soft` 等）。

### Tag / Badge

`bg --bg-subtle` / `--text-muted` / `radius 4px` / `padding 2px 8px` / `12px 500`。
状態を示すタグのみ semantic soft 背景 ＋ 対応する濃色文字。

### Divider

`1px solid --border`。**2px 以上の区切り線・二重線・破線は使わない。**

### Icon

線画 `1.5px` 単色（`--text` または `--text-muted`）、サイズ 16 / 20 / 24px。
**塗りアイコン・多色アイコン・装飾イラスト・ストックフォトは使わない。**

### Navigation（サイドバー）

`bg --bg-subtle` / 幅 240px / 項目 `height 28px, radius 4px, 14px`
hover `--bg-hover`、選択中 `--bg-hover` ＋ `font-weight 500`（**選択の表現に accent は使わない**）。

## 5. Layout Principles（レイアウト）

### スペーシングスケール（4px 基準）

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`
**この 9 段以外の値を使わない。** 「なんとなく 18px」が一貫性を壊す最大の原因。

### グリッド

- 12 カラム / gutter `24px`
- ドキュメント本文の最大幅 **720px**（1 行 40〜50 字）。全幅表示は表・図のみ
- ページ左右余白: デスクトップ `96px` / タブレット `48px` / モバイル `16px`

### 余白のリズム

| 関係 | 間隔 |
|---|---|
| ラベルと値 | 4px |
| 段落と段落 | 16px |
| 要素ブロック間 | 32px |
| セクション間 | 64px |

**近いものは近く、遠いものは遠く。** 余白を詰めて要素を増やすくらいなら、ページを分ける。

### 揃え

- **左揃えが基本。** 中央揃えは表紙・章扉・空状態のみ
- 数値は右揃え、単位は揃える
- 1 画面（1 ページ）＝ 1 メッセージ。主張が 2 つ入りそうなら分割する

## 6. Depth & Elevation（奥行き）

**この design system は「面」ではなく「線」で階層を作る。** 影はほぼ使わない。

| レベル | 用途 | 実装 |
|---|---|---|
| 0 | 本文・カード・表 | 影なし。`--bg-subtle` か `1px --border` で区切る |
| 1 | ドロップダウン・ポップオーバー | `0 0 0 1px rgba(15,15,15,.05), 0 3px 6px rgba(15,15,15,.1)` |
| 2 | モーダル・ダイアログ | `0 0 0 1px rgba(15,15,15,.05), 0 9px 24px rgba(15,15,15,.2)` ＋ 背面 `rgba(15,15,15,.6)` |

**レベル 1・2 は「本来そこに無いものが浮いている」ときだけ。** 通常のカードやセクションに影を付けない。
角丸は `4px`（小）/ `8px`（カード・モーダル）の 2 種のみ。

## 7. Do's and Don'ts（ガードレール）

### Do

- 迷ったら**余白を増やす**か**ページを割る**
- 強調は accent を **1 か所**に集中させる
- 図表は 3 色以内。注目させたい 1 系列だけ accent、残りはグレー
- 数値には**出典と期間**を必ず添える
- 状態は色＋語（`⚠ 遅延` のように）で示す
- 同じ意味には同じ語を使う（見出しと目次の文言を一致させる）

### Don't

- ❌ グラデーション・ドロップシャドウ・立体・3D グラフ・多系列の円グラフ
- ❌ 図表で 4 色以上（例外条件を満たす場合を除く）
- ❌ 装飾用のイラスト・写真・多色アイコン
- ❌ 1 画面／1 ページに主張を複数詰める
- ❌ 本文を 14px 未満に下げて情報を詰め込む
- ❌ 色だけで良し悪しを示す（赤＝悪 / 緑＝良）
- ❌ スペーシングスケール外の余白、角丸 4/8px 以外の値
- ❌ 中央揃えの本文、両端揃え、文字間の手動調整

## 8. Responsive Behavior（レスポンシブ）

| breakpoint | 幅 | 挙動 |
|---|---|---|
| mobile | `< 640px` | 1 カラム。サイドバーはドロワー。左右余白 16px。表は横スクロール |
| tablet | `640–1024px` | 2 カラム。サイドバー折りたたみ。左右余白 48px |
| desktop | `> 1024px` | 12 カラム。サイドバー常時表示。本文最大幅 720px |

- タッチターゲットは **最小 44×44px**（ボタン高さ 32px でも当たり判定を広げる）
- 表は縮小せず `overflow-x: auto` で横スクロール。**文字を小さくして収めない**
- 3 カラムのカードは tablet で 2 列、mobile で 1 列に折り返す
- 画像は `max-width: 100%`。トリミングよりレイアウト変更で対応する

## 9. Agent Prompt Guide（Claude Design への指示テンプレート）

このファイルを読み込ませたうえで、次の形で依頼する。

### 新規作成

```
このデザインシステムに従って <作るもの> を作って。
- 目的: <何を決めたい／伝えたいか>
- 対象: <誰が見るか>
- 制約: 図表は chart_palette の 3 色以内、1 画面 1 メッセージ
```

### スライド（詳細指示は指示書 YAML を併用）

```
このデザインシステムをスライドに適用して。
ページ構成と内容は添付の指示書 YAML（deck / page_templates / content）に従う。
デザインの判断はすべてこのデザインシステムを優先する。
```

→ 指示書 YAML の作り方は [docs/design/README.md](./README.md) を参照。

### 修正・レビュー

```
このデザインシステムに照らして、逸脱している箇所を指摘して直して。
特に「7. Do's and Don'ts」の Don't に該当する箇所を優先。
```

### 判断に迷ったときの原則（Claude 向け）

1. 未定義の値が必要になったら、**スペーシングスケール・3 色ルール・タイポスケールの範囲内**で最も近いものを選ぶ
2. 装飾を足すか迷ったら**足さない**
3. 色を増やすか迷ったら**グレースケールで階層を作れないか**を先に検討する
4. 情報が入りきらないときは、縮小ではなく**分割**する

## 付録: スライド（16:9）への適用

スライドは上記の値を **1920×1080px 基準にスケール**して使う。

| 項目 | 値 |
|---|---|
| アートボード | 1920 × 1080（16:9） |
| 余白 | 上 72 / 右 88 / 下 64 / 左 88 |
| ページタイトル | 40px / 700 / 1.3 |
| キーメッセージ | 28px / 600 / 1.5 |
| 本文 | 20px / 400 / 1.7 |
| ラベル | 16px / 500 / letter-spacing 0.04em |
| キャプション（出典） | 14px / 400 / `--text-muted` |
| ブロック間隔 | 32px |
| フッター | 左に案件名、右にページ番号（Caption スタイル） |

**投影用の追加ルール**

- 本文は **20px（= 実寸で十分読める）を下限**とする（§7 の「14px 未満」は Web / ドキュメント文脈の下限。スライドでは 20px が優先）
- 1 ページの根拠は 3 点まで。グラフは 1 ページ 1 つ、系列は 3 つまで
- 凡例より**直接ラベル**。グリッド線は最小限、枠線なし
- 最終ページには担当・期限・依頼事項を必ず置く
